# Resume Generator (MERN Stack)

A Resume Generator application built using the MERN stack.  
This application allows users to create professional resumes, analyze ATS scores, and manage resume templates through a secure admin dashboard.

---

## 🚀 Features

### 👤 User Module
- User Registration & Login
- Role-Based Authentication (User / Admin)
- Create & Edit Resume
- Live Resume Preview
- Profile Image Upload
- Multiple Professional Templates
- Print & Download Resume as PDF
- ATS Score Analyzer

### 🛠 Admin Module
- Admin Dashboard Overview
- Manage Users (View / Delete)
- Manage Resumes
- Add & Manage Templates
- Admin Profile Management

---

## 🏗 Tech Stack

### Frontend
- React.js

- Bootstrap
- React Router

### Backend
- Node.js
- Express.js

- JWT Authentication

## 📂 Project Structure

    root/

## ⚙️ Installation & Setup

### 1️⃣ Install Backend
    cd server
    npm install
    npm start

### 2️⃣ Install Frontend(new terminal)
    cd client
    npm install
    npm start


Application runs on:

Frontend → http://localhost:3000  
Backend → http://localhost:5000
